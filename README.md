# नवी दिशा — स्पर्धा परीक्षा संपूर्ण अभ्यास

हे GitHub Pages वर थेट चालणारे self-contained शैक्षणिक वेब अॅप आहे.

## मुख्य फाईल
- `index.html` — GitHub Pages साठी मुख्य प्रवेश फाईल.
- `app.js` — अभ्यासक्रम, ४० इंग्रजी घटक, MCQ आणि विषय विभाग.
- `style.css` — अॅपचे डिझाइन.
- `manifest.json` — PWA / app metadata.
- `icon.svg` — अॅप आयकॉन.
- `Navi_Disha_Spardha_Pariksha_Sampurna_Abhyas.pdf` — अभ्यास PDF.

## विषय विभाग
इंग्रजी, विज्ञान, भूगोल, इतिहास, नागरिकशास्त्र, समाजशास्त्र आणि गणित.

सध्या मूळ फाईलमधील इंग्रजीचे ४० घटक जतन केले आहेत. नवीन विषयांसाठी स्वतंत्र विभागाची रचना तयार आहे.

## GitHub Pages
सर्व फाईल्स repository च्या मुख्य (`main`) branch मध्ये upload करा. `index.html` चे नाव बदलू नका; GitHub Pages ला हे मुख्य प्रवेश पान म्हणून आवश्यक आहे.

## नाव
अॅपमध्ये सर्वत्र दिसणारे नाव:
